# Rhythm Pulse - K-Pop Dance Game

An anime 4D K-Pop rhythm dance game inspired by Pump It Up arcade.

## Features
- 30 K-Pop songs (BLACKPINK, BTS, TWICE, aespa, NewJeans, ITZY, IVE, (G)I-DLE, LE SSERAFIM, Red Velvet, STAYC, EXO)
- 3 difficulty levels: Easy / Normal / Hard
- 6-lane arrow system
- Keyboard controls: Arrow keys + WASD + Q/E
- PERFECT / GREAT / GOOD / BAD / MISS judgment system
- Combo counter, health bar, progress bar
- Grade system: S / A / B / C / D / F
- YouTube music video backgrounds
- Bilingual EN/VI support
- PWA installable (Android, iOS, Desktop)

## Tech Stack
- React 19 + TypeScript + Vite
- Tailwind CSS 4 + shadcn/ui
- Convex backend + database
- Hercules Auth (OIDC)
- react-youtube
- motion (Framer Motion)

## Controls
| Key | Lane |
|-----|------|
| Q | Up-Left |
| Arrow Left / A | Left |
| Arrow Down / S | Down |
| Arrow Up / W | Up |
| Arrow Right / D | Right |
| E | Up-Right |
| Space / Escape | Pause |

## Setup
```bash
pnpm install
pnpm dev
```
